### 👋 About

I build software, keep production systems reliable, and lead AI research and development. My work spans backend engineering, infrastructure and observability, and AI tools that solve practical problems.

Lately I'm deep into **harness engineering** — the layer around coding agents that makes them reliable: rules, skills, hooks, memory, sandboxes, and plan → build → judge loops. I've built a lot of personal harnesses that I run daily across Claude Code, Codex, and other agent CLIs.

```yaml
focus:
  engineering: [backend services, APIs, developer tools]
  reliability: [infrastructure, observability, incident response, automation]
  ai:          [applied AI, agent workflows, MCP, connecting models to real systems]
  harness:     [agent rules & skills, hooks, shared memory, sandboxed workspaces, multi-model loops]
off_hours:     [space, astronomy]
```
